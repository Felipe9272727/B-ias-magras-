# Formato de especificação de evento (para os pesquisadores e implementadores)

Cada evento no catálogo deve ser escrito assim (em português, com SUAS palavras — nunca copie o texto do jogo):

### <id_curto_em_snake_case> — <nome curto>
- grupo: porta | abrigo | radio | expedicao | cadeia:<nome> | final
- aparece quando: (dia mínimo/máximo, itens necessários, estado das pessoas, se é aleatório, se faz parte de uma cadeia e qual passo)
- frequência: (única / repete / chance, se a fonte disser)
- situação: 1–3 frases do que acontece
- escolhas:
  - <id_escolha> (requer: item/pessoa/nada): resultado(s) com chances, se houver → efeitos concretos (ganha/perde itens, estados, alguém sai, avança cadeia X, final Y)
- observações: o que a fonte não deixou claro

Números sempre que a fonte tiver. Se a fonte for de 60 Parsecs (o jogo espacial), IGNORE: só 60 Seconds! / Reatomized.
