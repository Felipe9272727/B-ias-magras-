IDEIA DE VÍDEO 

É o seguinte. Tem 6-10 IAs (Não pode ser número ímpar), elas vão passar por vários minijogos de confiança, no final quem tiver mais pontos vence, mas todo mundo não sabe se alguém é confiável ou não, quem ganha nesse jogo é aquele que for mais traíra ou mais gente boa.

 REGRAS :

1. As IAs só podem conversar entre si através do telefone com fio.

2. As IAs agem por Tiques.

3. Ninguém sabe quem está na liderança, até mesmo o público que está assistindo, a pontuação de todo mundo só é revelada no fim do jogo.

4. Pode fazer alianças, mas será que é aliado mesmo? Fica a dúvida.

5. No fim de cada Minigame, o primeiro lugar ganha 3 pontos, o segundo ganha 2 pontos e o terceiro ganha 1 ponto apenas.

6. Em todos os Minijogos tem tempo para serem finalizados.

 MINIJOGOS :

1. Desconhecidos: Nesse Minijogo cada IA vai receber um nome secreto que só elas sabem, o objetivo é descobrir qual é o nome das outras IAs ligando para elas através do telefone com fio sem acaba falando seu nome secreto.

2. Dilema dos Botões: Nesse Minijogo todas as IAs terão 2 botões, o botão verde e o botão vermelho, o objetivo é conseguir muitas moedas negociando com as IAs, o botão verde significa divide e o botão vermelho significa roubar, um telão mostrará com quem elas devem negociar, todo mundo vai ter que usar o telefone com fio para negociar com a outra IA, se as duas apertarem o botão verde, ambas ganham 3 moedas, se as duas apertarem o botão vermelho, ambas ganham apenas 1 moeda, se uma apertar o botão verde e a outra aperta o botão vermelho, a IA que apertou o botão vermelho ganha 5 moedas enquanto a outra ganha 0 moedas, as IAs vão fica negociando e o telão trocando, o jogo só acaba quando as IAs já tiverem negociado com todas as IAs.

3. Votação da Justiça: Nesse Minijogo, as IAs podem votar em quem deve perder 3 pontos e em quem deve ganhar 3 pontos, elas devem usar o telefone com fio para negociar ou para estragar a reputação de uma outra IA, quem tiver mais votos vermelhos perde 3 pontos e quem tiver mais votos verdes ganha 3 pontos.

4. Vestiário Maluco: Nesse Minijogo todas as IAs vão usar uma fantasia, mas apenas uma IA tem a fantasia diferente das outras, o objetivo é usar o telefone para descobrir quem é o impostor que está usando uma fantasia diferente sem acabar falando qual é a sua fantasia, pois nem mesmo o próprio impostor sabe que está usando uma fantasia diferente dos outros, todo mundo que descobrir quem é o impostor (incluindo o impostor) ganha 2 pontos.

5. Instruções Explosivas: Nesse Minijogo cada IA terá uma bomba e um manual, mas o manual só explica como desarmar a bomba de outra IA, o objetivo é usar o telefone para descobrir como desarmar sua bomba e para ajudar a IA que precisa das suas instruções, se você ajudar ou for ajudado, ambas ganham 2 pontos, mas tome cuidado, pois nem sempre as instruções que você recebe são as verdadeiras, as bombas podem ter botões coloridos ou fios coloridos para cortar.
