# Backup da partida 1 do Minecraft (6 IAs, 3 h + arena)

- `partida1_gravacao.tar.gz`: a gravação completa (`gravacoes/partida1`: eventos, posições, blocos, mobs, chunks) que o
  `replay.mjs` usa. Para restaurar: `tar -xzf backup/partida1_gravacao.tar.gz` dentro de `minecraft/`.
- `partida1_mundo.tar.gz`: o mundo do servidor no fim da partida (`servidor/mundo`), dá pra abrir no Minecraft Java 1.21.4.
